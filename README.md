# Optimized Drill & Pump Chaining (ODC)

Drills and pumps that touch each other act like one big pool, so a whole chain only needs one block touching an output.

Drills: each drill holds up to 150 items. Items flow through the chain toward the drill touching a conveyor, core or other block that accepts items, every drill drains completely.

Pumps: same as drills, but instead holds 150 liquid. Liquid is forwarded toward the pump touching a conduit or other liquid block.
